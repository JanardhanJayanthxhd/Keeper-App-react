# Keeper App

A simple note-taking app inspired by Google Keep. Create quick notes, keep them organized, and remove them when they are no longer needed.

## Description

Keeper App is a lightweight React project for saving short notes with a title and content. It is designed for fast, everyday capture and a clean, minimal interface.

## Tech Stack

- React
- Vite
- JavaScript
- Material UI

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

## Use

Start the app in development mode:

```bash
npm run dev
```

Then open the local URL shown in the terminal, add a note, and delete it when finished.
